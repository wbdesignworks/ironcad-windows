# IronCAD for Windows — Releases

Official Windows installer downloads for **IronCAD** by Ironclad Thor Industries LLC.

This repository is **distribution only** — no source code lives here. Grab the latest
installer from the [Releases](../../releases) page, or let the app auto-update via the
feed at https://ironcad.tech/updates/ironcad-desktop.

- `IronCAD-Setup-<version>.exe` — standard installer (NSIS)
- `IronCAD-<version>.exe` — portable, no install required

Source repository: `wbdesignworks/ironcad-desktop` (private).
